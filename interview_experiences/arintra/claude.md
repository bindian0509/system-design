Explore the system design problem and create comprehensive documentation:

1. Executive Summary - what is its core purpose?
2. Architecture - how is it structured? Include Mermaid diagrams.
3. Data Flows - how does data move in and out? Visualize with diagrams.
4. API Routes - what endpoints does it expose?
5. Database - what does it store? Include schema overview.
6. External Dependencies - what other services does it call? How?
7. Key Files - where's the important logic?
8. Common Gotchas - what breaks? What's confusing? What's undocumented?
9. Common Operations - how do you test/deploy/debug it?
10. Future Improvements - what could be better? What are the trade-offs?
11. Obseravbility - how do you monitor it? What metrics/logs/traces are important?
12. Security - how do you secure it? What are the potential vulnerabilities?
13. Performance - how do you ensure it meets the requirements? What are the bottlenecks

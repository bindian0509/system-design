# Company-Specific Interview Preparation Checklists

> **Purpose**: Tailored prep guides for different company types
> **Usage**: Review relevant checklist 2-3 days before interview

## Google Interview Checklist

### Process Overview
| Round | Duration | Focus |
|-------|----------|-------|
| Phone Screen | 45 min | Coding (LC Medium/Hard) |
| Onsite 1 | 45 min | Coding |
| Onsite 2 | 45 min | Coding |
| Onsite 3 | 45 min | System Design |
| Onsite 4 | 45 min | Googleyness & Leadership |
| (Optional) Onsite 5 | 45 min | Hiring Manager |

### Coding Preparation
- [ ] Practice coding in Google Docs (no autocomplete/syntax highlighting)
- [ ] Focus on optimal solutions - Google values efficiency
- [ ] Be ready to discuss time/space complexity
- [ ] Common topics: Arrays, Trees, Graphs, DP, Recursion

**Must-solve patterns:**
- [ ] BFS/DFS variations
- [ ] Binary Search variations
- [ ] Two pointers
- [ ] Sliding window
- [ ] Dynamic programming

### System Design Preparation
- [ ] Review: YouTube, Google Docs, Google Maps system designs
- [ ] Focus on scalability and distributed systems
- [ ] Be ready to discuss trade-offs deeply
- [ ] Draw clear diagrams, label everything

**Common problems:**
- [ ] Design YouTube
- [ ] Design Google Docs (collaborative editing)
- [ ] Design Google Search
- [ ] Design Google Maps
- [ ] Design Gmail

### Googleyness & Leadership
- [ ] Prepare 5-6 STAR stories covering:
  - [ ] Working with ambiguity
  - [ ] Influencing without authority
  - [ ] Handling conflict
  - [ ] Navigating difficult decisions
  - [ ] Showing intellectual humility

**Key traits Google looks for:**
- Comfort with ambiguity
- Collaboration
- Intellectual humility
- Bias for action
- User focus

### Day Before Checklist
- [ ] Review all STAR stories
- [ ] Do 1-2 warm-up coding problems
- [ ] Review system design approach
- [ ] Get good sleep
- [ ] Prepare questions for interviewers

### Interview Tips for Amazon
- [ ] ALWAYS tie answers back to LPs
- [ ] Use "I" not "we" - show personal ownership
- [ ] Be specific with metrics and data

## Microsoft Interview Checklist

### Process Overview
| Round | Duration | Focus |
|-------|----------|-------|
| Phone Screen | 45-60 min | Coding + Behavioral |
| Onsite 1 | 60 min | Coding |
| Onsite 2 | 60 min | System Design |
| Onsite 3 | 60 min | Behavioral |
| As Appropriate | 45 min | Senior leader, cultural fit |

### Key Values Microsoft Evaluates
1. **Growth Mindset** - Ability to learn and adapt
2. **Collaboration** - Working effectively with others
3. **Customer Focus** - Understanding user needs
4. **Technical Excellence** - Strong fundamentals

### Coding Preparation
- [ ] Practice in IDE but be ready for whiteboard
- [ ] Focus on clean, readable code
- [ ] Strong on OOP concepts
- [ ] Common topics: Arrays, Trees, OOD

### System Design Preparation
- [ ] Know Azure services (equivalent to AWS)
- [ ] Focus on reliability and scalability
- [ ] Be ready for hybrid on-prem/cloud scenarios

**Common problems:**
- [ ] Design Office 365
- [ ] Design Teams
- [ ] Design Xbox Live
- [ ] Design OneDrive

### Behavioral Preparation
Questions often asked:
- [ ] Tell me about a time you received critical feedback
- [ ] How do you approach learning new technologies?
- [ ] Describe a situation where you had to adapt
- [ ] Tell me about a time you helped someone grow

### "As Appropriate" Round Tips
- Final decision maker interview
- Focus on culture and leadership
- Be authentic and passionate
- Ask thoughtful questions about the role/team

## Day-of-Interview Checklist

### Morning Of
- [ ] Eat a good breakfast
- [ ] Review key notes (not new material)
- [ ] Test your video/audio setup
- [ ] Have water nearby
- [ ] Close unnecessary tabs/apps

### Technical Prep
- [ ] Have coding environment ready
- [ ] Paper/whiteboard for diagrams
- [ ] Calculator if needed

### Mental Prep
- [ ] Review 3-4 key STAR stories
- [ ] Remember: Interview is a conversation
- [ ] They want you to succeed
- [ ] It's okay to ask clarifying questions

### Questions to Ask Interviewers
1. What's the biggest challenge the team is facing?
2. How is success measured for this role?
3. What does a typical day look like?
4. How has the team evolved recently?
5. What's the team's tech stack and why?

### Post-Interview
- [ ] Send thank you notes (optional but nice)
- [ ] Note what went well/poorly for future prep
- [ ] Don't over-analyze - move to next opportunity

## Interview Prep Timeline

### 1 Week Before
- [ ] Research company (news, products, culture)
- [ ] Review relevant system designs
- [ ] Map STAR stories to company values
- [ ] Do mock interview if possible

### 3 Days Before
- [ ] Review company-specific checklist
- [ ] Light coding practice (don't burn out)
- [ ] Finalize questions to ask

### 1 Day Before
- [ ] Light review only
- [ ] Get good sleep
- [ ] Prepare logistics (login links, etc.)
- [ ] Lay out professional attire

### Day Of
- [ ] Morning warm-up (1 easy problem)
- [ ] Review STAR stories
- [ ] Arrive/login early
- [ ] Stay calm and be yourself

System design a Cart Management module/system. The Cart system is designed to display orders placed, including their status and managing them (cancel, modify, etc). You can start by providing how the cart at Uber works and state what our limitations are (i.e. multiple items to be added from different merchants, etc). Focus and generate architectural diagrams and at most method prototypes, not to go into any actual implementation. Coding is not desired, however, if you think some snippets of code will help to understand or unblock, you can spend some thinking there. Expand the scope of the solution to support CRUD operations. 


Follow-Up Questions 

Expanding the cart to display orders generated by sub-users (i.e. teens, etc). Think from the perspective of Read only orders or similar.

Integrations with 3rd parties. For example partnering with other providers for other types of items. Think on over overloading new types of orders and how to limit certain operations.


Offline behavior

Make sure to proposes a suitable data model for supporting types such as "Delivery" (you select to have a driver to deliver this to you), "Pick up" (you pick up the item or items), "Pick up with Ride" (a ride is booked for you and you pick up your items). please cover the data model and the different components that will compose the solution.

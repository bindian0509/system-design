# Query Equivalence Checking

## Overview

Query equivalence checking ensures that LLM-generated SQL queries return the same results as expected for a given natural language request. This is critical for:

1. **Testing** - Validate that generated queries are correct
2. **Regression detection** - Catch breaking changes in prompts/models
3. **Confidence scoring** - Higher confidence when query matches known patterns
4. **Audit** - Verify queries meet DSAR requirements

---

## The Equivalence Problem

### Challenge

Two SQL queries can be **semantically equivalent** while being **syntactically different**:

```sql
-- Query A (generated by LLM)
SELECT id, amount, currency
FROM payments
WHERE user_id = $1 AND created_at >= $2

-- Query B (reference query)
SELECT payments.id, payments.amount, payments.currency
FROM payments
WHERE payments.user_id = $1 AND payments.created_at >= $2

-- Query C (also equivalent)
SELECT id, amount, currency
FROM payments p
WHERE p.user_id = $1 AND p.created_at >= $2
```

All three queries return identical results, but string comparison would flag them as different.

---

## Equivalence Checking Approaches

### 1. Normalized AST Comparison

Convert both queries to a normalized Abstract Syntax Tree and compare.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        AST NORMALIZATION                                     │
└─────────────────────────────────────────────────────────────────────────────┘

    Query: SELECT id, amount FROM payments WHERE user_id = $1

    ┌────────────────────────────────────────────────────────────────────┐
    │  PARSE                                                             │
    │                                                                     │
    │  SelectStatement                                                   │
    │  ├── columns: [id, amount]                                         │
    │  ├── from: payments                                                │
    │  └── where: user_id = $1                                           │
    └────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
    ┌────────────────────────────────────────────────────────────────────┐
    │  NORMALIZE                                                         │
    │                                                                     │
    │  • Remove table aliases                                            │
    │  • Fully qualify column names                                      │
    │  • Sort columns alphabetically                                     │
    │  • Normalize whitespace                                            │
    │  • Standardize parameter placeholders                              │
    └────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
    ┌────────────────────────────────────────────────────────────────────┐
    │  NORMALIZED AST                                                    │
    │                                                                     │
    │  {                                                                 │
    │    "type": "SELECT",                                               │
    │    "columns": ["payments.amount", "payments.id"],                  │
    │    "from": ["payments"],                                           │
    │    "where": {"payments.user_id": {"eq": "$1"}}                     │
    │  }                                                                 │
    └────────────────────────────────────────────────────────────────────┘
```

**Implementation:**

```python
from dataclasses import dataclass
import sqlparse
from sqlparse.sql import IdentifierList, Identifier, Where

@dataclass
class NormalizedQuery:
    query_type: str
    columns: list[str]
    tables: list[str]
    where_conditions: dict
    order_by: list[str] | None = None
    limit: int | None = None

class QueryNormalizer:
    def normalize(self, sql: str) -> NormalizedQuery:
        parsed = sqlparse.parse(sql)[0]

        return NormalizedQuery(
            query_type=parsed.get_type(),
            columns=sorted(self._extract_columns(parsed)),
            tables=sorted(self._extract_tables(parsed)),
            where_conditions=self._normalize_where(parsed),
            order_by=self._extract_order_by(parsed),
            limit=self._extract_limit(parsed),
        )

    def are_equivalent(self, query_a: str, query_b: str) -> bool:
        norm_a = self.normalize(query_a)
        norm_b = self.normalize(query_b)
        return norm_a == norm_b
```

**Implementation:**

```python
import hashlib
from typing import Any

class ResultSetComparator:
    def __init__(self, db_connection):
        self.db = db_connection

    async def compare(
        self,
        query_a: str,
        params_a: list,
        query_b: str,
        params_b: list,
    ) -> bool:
        results_a = await self.db.fetch(query_a, *params_a)
        results_b = await self.db.fetch(query_b, *params_b)

        # Convert to comparable format (order-independent)
        set_a = self._to_comparable_set(results_a)
        set_b = self._to_comparable_set(results_b)

        return set_a == set_b

    def _to_comparable_set(self, rows: list[dict]) -> set[str]:
        # Hash each row for comparison
        return {
            hashlib.md5(
                str(sorted(row.items())).encode()
            ).hexdigest()
            for row in rows
        }
```

### 3. Semantic Fingerprinting

Generate a semantic fingerprint based on query structure, not syntax.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        SEMANTIC FINGERPRINT                                  │
└─────────────────────────────────────────────────────────────────────────────┘

    Query: SELECT id, amount FROM payments WHERE user_id = $1 AND created_at >= $2

    Fingerprint components:
    ┌────────────────────────────────────────────────────────────────────┐
    │  tables:      [payments]                                           │
    │  columns:     [id, amount]                                         │
    │  filters:     [user_id=param, created_at>=param]                   │
    │  joins:       []                                                   │
    │  aggregates:  []                                                   │
    │  order:       none                                                 │
    │  limit:       none                                                 │
    └────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
    Fingerprint: "payments|amount,id|created_at>=,user_id=|"

    Two queries with same fingerprint are semantically equivalent.
```

**Implementation:**

```python
class SemanticFingerprinter:
    def fingerprint(self, sql: str) -> str:
        parsed = sqlparse.parse(sql)[0]

        components = [
            self._tables_component(parsed),
            self._columns_component(parsed),
            self._filters_component(parsed),
            self._joins_component(parsed),
            self._aggregates_component(parsed),
        ]

        return "|".join(components)

    def _tables_component(self, stmt) -> str:
        tables = sorted(self._extract_tables(stmt))
        return ",".join(tables)

    def _columns_component(self, stmt) -> str:
        columns = sorted(self._extract_columns(stmt))
        return ",".join(columns)

    def _filters_component(self, stmt) -> str:
        # Extract filter patterns (column + operator, not values)
        filters = []
        for condition in self._extract_where_conditions(stmt):
            column = condition["column"]
            operator = condition["operator"]
            filters.append(f"{column}{operator}")
        return ",".join(sorted(filters))

    def are_equivalent(self, query_a: str, query_b: str) -> bool:
        return self.fingerprint(query_a) == self.fingerprint(query_b)
```

## Equivalence Classes

Define equivalence classes for common DSAR query patterns:

```python
EQUIVALENCE_CLASSES = {
    "user_profile": {
        "tables": ["users"],
        "required_columns": ["id", "email", "name"],
        "optional_columns": ["phone", "created_at"],
        "required_filters": ["user_id"],
        "description": "Basic user profile data",
    },
    "payment_history": {
        "tables": ["payments"],
        "required_columns": ["id", "amount", "currency", "created_at"],
        "optional_columns": ["status", "payment_method_type"],
        "required_filters": ["user_id"],
        "optional_filters": ["created_at"],
        "description": "User payment transaction history",
    },
    "trip_history": {
        "tables": ["trips"],
        "required_columns": ["id", "origin", "destination", "fare"],
        "optional_columns": ["started_at", "ended_at", "status"],
        "required_filters": ["user_id"],
        "optional_filters": ["started_at"],
        "description": "User trip history",
    },
}

class EquivalenceClassMatcher:
    def match(self, query: NormalizedQuery) -> str | None:
        """Return the equivalence class name if query matches, None otherwise."""
        for class_name, spec in EQUIVALENCE_CLASSES.items():
            if self._matches_spec(query, spec):
                return class_name
        return None

    def _matches_spec(self, query: NormalizedQuery, spec: dict) -> bool:
        # Check tables
        if set(query.tables) != set(spec["tables"]):
            return False

        # Check required columns present
        query_cols = set(query.columns)
        required_cols = set(spec["required_columns"])
        if not required_cols.issubset(query_cols):
            return False

        # Check no unexpected columns
        allowed_cols = required_cols | set(spec.get("optional_columns", []))
        if not query_cols.issubset(allowed_cols):
            return False

        # Check required filters
        query_filters = set(query.where_conditions.keys())
        required_filters = set(spec["required_filters"])
        if not required_filters.issubset(query_filters):
            return False

        return True
```

## Testing with Equivalence Checking

### Unit Tests

```python
import pytest
from dsar_query_generator.services.equivalence import QueryNormalizer

class TestQueryEquivalence:
    def setup_method(self):
        self.normalizer = QueryNormalizer()

    def test_column_order_equivalence(self):
        query_a = "SELECT id, amount, currency FROM payments WHERE user_id = $1"
        query_b = "SELECT currency, id, amount FROM payments WHERE user_id = $1"
        assert self.normalizer.are_equivalent(query_a, query_b)

    def test_alias_equivalence(self):
        query_a = "SELECT id, amount FROM payments WHERE user_id = $1"
        query_b = "SELECT p.id, p.amount FROM payments p WHERE p.user_id = $1"
        assert self.normalizer.are_equivalent(query_a, query_b)

    def test_qualified_names_equivalence(self):
        query_a = "SELECT id, amount FROM payments WHERE user_id = $1"
        query_b = "SELECT payments.id, payments.amount FROM payments WHERE payments.user_id = $1"
        assert self.normalizer.are_equivalent(query_a, query_b)

    def test_non_equivalence_different_columns(self):
        query_a = "SELECT id, amount FROM payments WHERE user_id = $1"
        query_b = "SELECT id, currency FROM payments WHERE user_id = $1"
        assert not self.normalizer.are_equivalent(query_a, query_b)

    def test_non_equivalence_different_tables(self):
        query_a = "SELECT id, amount FROM payments WHERE user_id = $1"
        query_b = "SELECT id, amount FROM refunds WHERE user_id = $1"
        assert not self.normalizer.are_equivalent(query_a, query_b)
```

## Confidence Scoring Integration

Use equivalence checking to boost confidence scores:

```python
class ConfidenceScorer:
    def score(self, query: GeneratedQuery, request: str) -> str:
        base_score = self._llm_confidence(query)
        equiv_class = self.matcher.match(query.normalized)

        # Boost confidence if matches known pattern
        if equiv_class is not None:
            if base_score == "low":
                return "medium"
            elif base_score == "medium":
                return "high"

        return base_score

    def _llm_confidence(self, query: GeneratedQuery) -> str:
        # Trust LLM's self-reported confidence as baseline
        return query.confidence
```

## Summary

| Approach | Use Case | Pros | Cons |
|----------|----------|------|------|
| AST Normalization | Unit testing, validation | Fast, no DB needed | Complex SQL may not normalize well |
| Result Set Comparison | Integration testing | Ground truth | Requires test DB, slow |
| Semantic Fingerprinting | Regression detection, CI | Fast, captures intent | May miss subtle differences |
| Equivalence Classes | Pattern matching, confidence | Interpretable, maintainable | Requires manual class definition |

**Recommended approach:** Combine semantic fingerprinting for fast CI checks with result set comparison for thorough integration testing.

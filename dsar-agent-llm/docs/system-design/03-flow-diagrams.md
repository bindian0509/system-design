## Agentic Loop Flow (Enhanced)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           AGENTIC LOOP FLOW                                  │
│                   Research → Generate → Verify → Refine                      │
└─────────────────────────────────────────────────────────────────────────────┘

                              ┌──────────────┐
                              │   Request    │
                              │   Received   │
                              └──────┬───────┘
                                     │
                                     ▼
                    ┌────────────────────────────────┐
                    │         1. RESEARCH            │
                    │  ┌──────────────────────────┐  │
                    │  │ • Parse user intent      │  │
                    │  │ • Identify relevant      │  │
                    │  │   tables from schema     │  │
                    │  │ • Check for ambiguity    │  │
                    │  │ • Map to data categories │  │
                    │  └──────────────────────────┘  │
                    └────────────────┬───────────────┘
                                     │
                         ┌───────────┴───────────┐
                         ▼                       ▼
                   ┌──────────┐           ┌──────────────┐
                   │ Clear    │           │  Ambiguous   │
                   │ Intent   │           │  Request     │
                   └────┬─────┘           └──────┬───────┘
                        │                        │
                        │                        ▼
                        │              ┌─────────────────┐
                        │              │Return Clarify   │
                        │              │Request to User  │
                        │              └─────────────────┘
                        │
                        ▼
                    ┌────────────────────────────────┐
                    │         2. GENERATE            │
                    │  ┌──────────────────────────┐  │
                    │  │ • Build SQL query        │  │
                    │  │ • Use parameterized      │  │
                    │  │   placeholders ($1,$2)   │  │
                    │  │ • Include only allowed   │  │
                    │  │   columns                │  │
                    │  └──────────────────────────┘  │
                    └────────────────┬───────────────┘
                                     │
                                     ▼
                    ┌────────────────────────────────┐
                    │         3. VERIFY              │
                    │  ┌──────────────────────────┐  │
                    │  │ • Parse SQL (sqlparse)   │  │
                    │  │ • Check SELECT only      │  │
                    │  │ • Validate tables        │  │
                    │  │ • Validate columns       │  │
                    │  │ • Check parameterization │  │
                    │  │ • Enforce table limits   │  │
                    │  └──────────────────────────┘  │
                    └────────────────┬───────────────┘
                                     │
                         ┌───────────┴───────────┐
                         ▼                       ▼
                   ┌──────────┐           ┌──────────────┐
                   │  Valid   │           │   Invalid    │
                   │  Query   │           │   Query      │
                   └────┬─────┘           └──────┬───────┘
                        │                        │
                        │                        ▼
                        │          ┌────────────────────────────┐
                        │          │         4. REFINE          │
                        │          │  ┌──────────────────────┐  │
                        │          │  │ • Add error to prompt│  │
                        │          │  │ • Request correction │  │
                        │          │  │ • Max 2 retries      │  │
                        │          │  └──────────────────────┘  │
                        │          └──────────────┬─────────────┘
                        │                         │
                        │             ┌───────────┴───────────┐
                        │             ▼                       ▼
                        │      ┌──────────┐           ┌──────────────┐
                        │      │  Retry   │           │  Max Retries │
                        │      │  Loop    │──────────▶│  Exceeded    │
                        │      └────┬─────┘           └──────┬───────┘
                        │           │                        │
                        │           │ (back to Generate)     ▼
                        │           │                 ┌──────────────┐
                        │           │                 │Return Error  │
                        │           │                 │to User       │
                        │                             └──────────────┘
                        ▼
                    ┌────────────────────────────────┐
                    │           COMPLETE             │
                    │  ┌──────────────────────────┐  │
                    │  │ • Log to audit trail     │  │
                    │  │ • Return query + params  │  │
                    │  │ • Include confidence     │  │
                    │  │ • Flag for review        │  │
                    │  └──────────────────────────┘  │
                    └────────────────────────────────┘
```

## Error Handling Flow

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           ERROR HANDLING PATHS                               │
└─────────────────────────────────────────────────────────────────────────────┘

    ┌──────────────────────────────────────────────────────────────────────┐
    │                        VALIDATION FAILURES                            │
    └──────────────────────────────────────────────────────────────────────┘

    ┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌──────────┐
    │  Non-SELECT │     │  Blocked    │     │  Excluded   │     │  Literal │
    │   Query     │     │   Table     │     │   Column    │     │  Values  │
    └──────┬──────┘     └──────┬──────┘     └──────┬──────┘     └────┬─────┘
           │                   │                   │                  │
           ▼                   ▼                   ▼                  ▼
    ┌─────────────────────────────────────────────────────────────────────┐
    │                          REFINE LOOP                                 │
    │   Add validation error to prompt → Request LLM to fix → Re-validate │
    └─────────────────────────────────────────────────────────────────────┘
           │
           │ After max retries
           ▼
    ┌─────────────────────────────────────────────────────────────────────┐
    │                         RETURN ERROR                                 │
    │   • Error type                                                       │
    │   • Specific reason                                                  │
    │   • Request ID for debugging                                         │
    └─────────────────────────────────────────────────────────────────────┘


    ┌──────────────────────────────────────────────────────────────────────┐
    │                        SPECIAL CASES                                  │
    └──────────────────────────────────────────────────────────────────────┘

    ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
    │  Ambiguous  │     │ Out of Scope│     │  Multi-Table│
    │  Request    │     │  (Delete)   │     │  Request    │
    └──────┬──────┘     └──────┬──────┘     └──────┬──────┘
           │                   │                   │
           ▼                   ▼                   ▼
    ┌────────────┐     ┌────────────┐     ┌─────────────────┐
    │ Clarify    │     │ Out of     │     │ Multiple Queries│
    │ Response   │     │ Scope Resp │     │ with Note       │
    │            │     │            │     │                 │
    │ suggestions│     │ escalation │     │ [query1, ...]   │
    │ [opt1,..] │      │ _path      │     │ "Assemble       │
    └────────────┘     └────────────┘     │  results"       │
                                          └─────────────────┘
```
